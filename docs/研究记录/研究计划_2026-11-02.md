## 2. 研究问题与可检验假说

| 问题 | 待检验假说 | 主要判别证据 |
|---|---|---|
| 空白段如何产生？ | 相对滑移停止、离面、低于沉积检测限可能分别或共同贡献 | 同步相对速度、离面位移和 N(t)，结合图像检测限；无法分辨时标记“未判定” |
| 单痕平台、肩峰、多峰从何而来？ | 有限足迹、成像与非均匀沉积可产生类似形态，未必对应多次力峰或碰撞 | 独立足迹与光学标定；上/中/下窄带和整痕剖面共同对照；运动学提供事件数 |
| 虚线周期由什么决定？ | 摩擦、结构柔度与接触/再加载共同控制周期，单次滑移时长仅占其中一部分 | 多周期同步数据；冻结参数后预测周期、点距、点长及其工况依赖 |
| “速度大时要更用力”是否成立？ | 存在速度—法向载荷的虚线形成区域 | 固定其他条件分别变速、变载荷，并作升/降扫描；不预设 N 与 v 成正比 |
| 笔痕能反演哪些量？ | 几何与周期相关量可能先可辨识，瞬时 N(t) 需要更强标定与动态验证 | 参数相关性、观测敏感性及独立留出数据上的反演误差 |

本轮不预设唯一机理。纯黏滑、离面跳跃与再接触、回划或多次沉积均保留为候选；reverse chatter 的判定须有相应运动与接触序列证据。

## 3. 统一测量与模型接口

### 3.1 参数、坐标与版本

1. 以“粉笔样品—板面区域—装置配置—试次”为最小可追溯单元，记录材料批次、清洁/预磨、温湿度、夹持位置、粉笔自由长度及采集参数。
2. 区分 E1 的斜面临界角与粉笔接触角。接触角统一注明“相对板面”或“相对法线”，换算后再传入模型，不直接混用旧 α 与 θ。
3. 区分板速、手端推进速度和接触点相对滑移速度。所有扫描以实测速率为横轴，驱动设定值另存。
4. 实测整支长度不直接替代等效杆长；先核实夹持边界。质量优先称量，惯量按实际形状和质量分布估算并给出不确定度。
5. 原 v1/v2 占位基线保留；用独立的“实测参数版本”承接新数据。E1初测不直接覆盖 μs=0.62，更不由此推定 μk 或摩擦比。

### 3.2 主要终点

| 层次 | 主要记录量 | 解释范围 |
|---|---|---|
| 可重复现象 | 连续/规则虚线/不规则的状态、重复性、点长、点距、空白长度 | 用独立笔画统计；单条笔画中的多个痕迹作为组内样本 |
| 时间与运动 | 已核实同相位事件间隔 T、推进轨迹、相对滑移、离面与再接触 | 声学事件数、笔痕数、接触事件数分别记录 |
| 力学 | N(t)、切向力、痕端时刻的接触状态、再加载过程 | 仅解释已通过带宽和同步验收的时间尺度 |
| 图像 | 二维轮廓、窄带剖面、横向积分亮度 J(x)、边缘宽度、近上限像素比例 | J 为光学量，不直接等于模型沉积 I、粉尘质量或 N |
| 模型 | 周期、单次滑移时长、黏着/离面时长、事件次序与预测笔痕 | 单事件停止、持续黏着、稳定周期分别验收 |

只有确认相邻声学事件对应相邻笔痕的同一相位后，才使用 Tᵢ=tᵢ₊₁−tᵢ、λᵢ=xᵢ₊₁−xᵢ 与平均推进速度 λᵢ/Tᵢ。一般变速情况优先比较相邻标记之间的实测推进距离；仅在恒速且相位对应成立时使用 λ=vT。

## 4. 实验测量计划

### 4.1 P0：先补齐原始记录与成像条件

- 为现有 E1、两组图像/录音和尺寸记录补建样品、试次和文件对应表；不补造缺失条件。核实原始媒体可访问位置、校验值及备份，保存原始文件和处理参数。
- 首轮补拍保留同平面尺标、空白背景和固定机位；同一组痕迹拍正常及至少两档较低曝光，检查亮部是否仍有纹理。原 JPEG 软件调暗不能替代补拍。
- 选择孤立、未重叠的痕迹近拍；先争取每痕沿书写方向至少约50个真实像素，再通过分辨率/模糊敏感性决定是否足以判别边缘。未达到要求仍可做几何统计，不用于微观截断结论。
- 在受控稳定滑动、可重复轻触或短位移印迹中估计足迹及其随载荷、接触角和磨损的变化。干燥笔痕轮廓作为观测核的参考，不能直接等同于真实接触斑。
- 选至少3次独立书写，每次取若干可用痕迹；标定组与留出组按整次书写/不同日期分开，避免把同一笔画的相邻痕迹分到两组。

**交付与验收：**原始数据索引、带尺标且不过曝的二维图像、曝光与背景敏感性记录、观测核适用条件。若现有光学条件仍不能区分痕端形态，先保留“图像不可判别”，不强行要求模型产生截断。

### 4.2 E1：从阈值夹逼升级为可用静摩擦标定

- 核实60.0 cm是否为有效斜面长度、h是否为两端竖直高差，以及现有上下界是否夹逼同一条件。确认粉笔没有滚动/倾覆，记录实际接触面；接触方式与书写尖端不同的数据分别保存。
- 先做约10次独立起滑预试验，固定加载速率、等待规程和表面处理；正式基准条件按既有方案完成至少30次，保留各试次临界值或阈值区间。
- 条件稳定后再做等待时间扫描，建议先用1、10、60 s三档，每档至少10次筛查；是否加密与扩充重复数由离散度决定。记录实际停止至起滑时间，检验时间依赖，不预设对数增长必然成立。
- 报告仪器与几何误差、试次间离散度；上下界数据按区间观测处理。比较不同接触方式，确定哪一组 μs 可用于后续装置。

**交付与验收：**含元数据的原始表、μs分布/区间及不确定度、接触方式适用范围。μs≈0.686作为初测参考保留，完成上述核查后才进入实测参数版本。

### 4.3 E2 / E3：先约束摩擦与柔度，再拟合瞬态

| 任务 | 最小实验安排 | 交付与限制 |
|---|---|---|
| E2 稳态动摩擦 | 建议实测速率5、10、20、50、100、200 mm/s；每档至少3次独立运行，在受控接触与载荷下测切向力/法向力，并记录稳态有效区间 | μk(v,N)及不确定度；先判断速率趋势，不预设必须符合某种经验式 |
| E2 动态补充 | 在装置可控的范围内作至少两组速度阶跃，以及滑移—停止—再滑移；分开改变等待时间与加载过程 | 约束状态记忆、Stribeck尺度或LuGre瞬态参数；若不可辨识，只给范围或简化本构 |
| E3 静态柔度 | 两向分别加载并作升/降载，至少5个载荷级、3次重复；测位移与转角，先检验线性及交叉耦合 | 装置的有效柔度/刚度矩阵；人手、夹具和粉笔边界分别记录 |
| E3 动态与几何 | 称量样品、记录自由长度；测可分辨模态及衰减，必要时独立测弯曲响应 | 质量、等效惯量、刚度/阻尼范围与留出工况预测；未验证边界前不直接套 kθ=3EI/L |

挂重滑轮可用于静态加载或探索驱动；用于E2/E4时必须实测速度和加速度，处理张力、滑轮与惯性影响，不能把固定挂重视为恒速源。所有数值对照使用实际测得的驱动轨迹。

### 4.4 E4 / E5：建立受控虚线与同步事件记录

1. 固定一批粉笔、板面规程、接触角与夹持结构，先找出一个能重复出现虚线的条件，每次记录完整笔画及驱动轨迹。
2. 在此附近做3档实际速度×3档法向载荷，每组合至少3次独立笔画，共至少27次。速度优先覆盖20、50、100 mm/s；若不在可重复虚线区，以预试验确定的实际范围替换。载荷低/中/高档由装置量程和可重复区确定，不沿用占位N₀=4 N作既定值。
3. 随机化条件顺序，记录磨损及板面位置；每次争取获得至少20个完整候选周期。达不到时保留失败/短序列，不只挑规则片段。
4. 先完成声学—视频—驱动轨迹的公共事件同步与延迟核查，再加入法向/切向力。用独立触发或可追踪的同步事件量化时钟偏移、漂移和声传播延迟；逐个核实声峰与运动/笔痕相位。
5. 对痕端作“滑移停止但仍接触 / 脱离 / 再接触冲击 / 低于检测限 / 未判定”的标记，保留各通道判据和不确定度。声音本身不足以认定碰撞。

**测量链按目标分级：**10–20 ms的现有声学重复尺度只用于规划。240 fps的帧间隔约4.17 ms，可作粗运动跟踪，不能用于判定亚毫秒痕端次序。若首轮目标是分辨1 ms过程，力采样先按≥10 kS/s、视频按约10 kfps的量级规划，并独立验收传感器带宽、安装共振、曝光与同步误差；若预试验事件更短，重新核定。缺少相应硬件时，只报告已分辨的周期/运动量，保留痕端机理未决。

**交付与验收：**一个可重复虚线基准、实际速度—载荷状态图初版、同步误差预算，以及至少一组可人工核验的连续事件序列。状态图标注重复数、失败率和不确定区域，不由27次笔画直接宣称高精度相边界。

### 4.5 E6 / E6A：将痕端判别与正向观测标定结合

- 每痕同时保存二维图、上/中/下窄带及整痕积分J(x)，检查阈值、背景、曝光、散粉和重叠的影响；不同曝光下先验证形状和结束位置的稳定性。
- 在受控稳定滑动和多级法向力下标定光学响应、足迹与沉积代理的关系；分别检验升/降载、速度和磨损依赖，不预设一条普适J—N曲线。
- 由同步动力学输出经过观测模型预测二维图，再比较剖面。先在留出稳定条件检验，再用非恒定N(t)做动态验证。
- “有限强度截断”改为候选判别特征；只有空间分辨率、足迹与相机效应受控，并有同步力/运动证据时才赋予力学解释。图像零值和多峰都不单独作为脱离或碰撞证据。

## 5. 仿真实验与数值计算计划

### 5.1 S8 扩展：检验观测层能分辨什么

沿用 `observation_model.py` 和统一沉积后处理，推进以下三项：

1. 从预设像素跨度改为独立尺标与运动轨迹约束的空间尺度；用标定组估计足迹、模糊及相机响应，不在每个留出笔痕上重新自由调整全部参数。
2. 系统比较点足迹、有限直立/倾斜足迹，以及恒定/下降沉积源；同时评价二维残差、窄带峰位、积分剖面和边缘，不只看一条归一化曲线。
3. 以重复测量噪声、核参数不确定度和模型间差异比较可辨识性。若两类源在观测层不可区分，报告“仅凭图像不足以判断”，并据此指定需要补测的运动或力通道。

验收：卷积与模糊前后的沉积代理总量守恒、相机响应处理次序正确；固定观测参数后完成按独立笔画划分的留出预测。相机非线性响应后的灰度积分不要求守恒。

### 5.2 实测工况下的 v2 单事件计算

- 将几何、质量、驱动轨迹、摩擦与柔度的可用测量依次写入新参数集；每项标明实测、派生或待辨识，传播参数不确定度。
- 先覆盖实验已测速度和载荷，对照滑移距离、停止/再滑移与力波形；重点解释既有低速工况点长过短的问题，区分参数不符、初始化、缺少再加载或观测展宽，避免只调摩擦比追形状。
- 联合约束接触刚度kn、法向支撑刚度ky及阻尼；没有独立压入或运动测量时，优先报告可辨识的等效组合，不宣称分别标定成功。
- 修正/对照大角度刚性接触的初始锚定，采用满足接触约束及实际预载过程的可行初态；排查接触振铃和首次过零后的再滑移。
- 罚接触与刚性接触作为不同建模口径比较；只在已检查工况中引用差异，旧基线7%–15%的差异不能外推为全域界限。

验收：实际工况下数值误差小于目标实验不确定度；事件类型对容差、步长和初始化检查稳定。数值收敛与参数敏感性分别报告，不以增加kn替代积分收敛检查。

### 5.3 S9（拟新增）：完整周期与再加载

S9为后续任务编号，本次只制定计划，尚无已完成结果。

- 在v2基础上实现连续加载、黏着/滑移切换、必要的离面和再接触；若测到离面再引入并标定碰撞律，先保持最少的可辨识自由参数。
- 先检验持续接触的黏滑周期能否解释数据，再与含飞行/冲击的版本比较。首停不终止全部计算，不把首次速度过零当稳定黏着。
- 摩擦内态和结构状态按物理规则跨事件传递；人工N₀、角速度和内态逐步改由实际加载及前一周期产生。区分驱动设定载荷与周期初始瞬时力。
- 积分至少覆盖20个候选周期，检查瞬态衰减、周期漂移、事件密集/颤振及初态依赖；在可行条件下扰动初态，检验周期稳定性。
- 输出T、点距、点长、空白、黏着/滑移/飞行时间及事件序列，经S8生成预测笔痕。已有10–20 ms声学尺度只有在事件对应核实后才转作周期验证目标。

验收：形成可复现的多周期解或明确的非周期结果；若没有周期，不通过人为重置状态制造周期。给出接触约束、能量/功率收支、沉积守恒与事件处理检查；刚性接触仅在适用且初始化已验证的工况使用。

### 5.4 S10（拟新增）：实测参数冻结后的对照与边界

- 冻结实验标定及模型选择，用未参与拟合的整次书写、载荷/速度组合和不同日期数据检验。
- 首先验证周期、点距、点长和事件类别；其次验证二维笔痕及痕端。误差与实验重复性、参数传播及模型差异并列报告。
- 若主要差异集中在速度—载荷状态转换区，再做自适应加密、升速/降速与升载/降载扫描；角度与柔度作为后续轴加入，避免一开始全因素铺开。
- 若必须重调参数，原留出组转入标定集，另取新的留出组；若无法区分候选模型，保留并列解释和可检验的差异预测。

## 7. E7 / E8的启动条件与研究边界

**E7痕迹反演：**先评估点距、周期关联推进速度、平均载荷或事件类型等较低维目标。尺度、相位对应与动态观测模型未经验证时，不进行瞬时N(t)盲反演。验证时报告失败率、误差和不可辨识工况；不以同一图像既定核又验证自身。

**E8材料推广：**单一粉笔—黑板体系通过独立验证后，再选2–3组材料/表面对照，重新测摩擦、磨损与光学响应。比较无量纲趋势和事件类别，不直接复用原材料参数。若主线进度受限，E7/E8顺延，优先完成一个体系的闭环。

本轮不把以下事项列为前置必达：用旧v1继续大范围寻找奇异；从手绘图像直接恢复绝对N(t)；分辨旧S3占位参数预言的微秒级滞后；一次性辨识全部LuGre/率态参数；在完整周期验证前全面扩展连续梁模型。只有新数据证明这些工作必要且可辨识时再启动。

## 8. 风险、判退与成果管理

| 风险或失败情形 | 处置 |
|---|---|
| 补拍后仍有高光上限、足迹/像素限制 | 保留几何与周期结果；停止用该批数据判断微观痕端或绝对沉积 |
| 声峰与笔痕一对多或相位不清 | 保留声学重复频率；不使用λ/T逐点恢复速度 |
| 无法稳定控制速度、载荷或夹持 | 先记录真实输入与柔度，缩小到可重复区；不宣称扫出材料固有相边界 |
| 参数高度相关或力传感器受结构惯性污染 | 增加独立测量，或使用有效参数/范围；保留不可辨识结论 |
| 完整周期不能持续，或依赖人为重置 | 检查实际驱动、边界、静摩擦状态与再加载；明确模型未通过，不靠继续拟合照片掩盖 |
| 留出预测未通过 | 报告失败工况与残差，区分观测层、参数层和动力学层；修改后使用新留出数据 |

每轮保存原始数据/索引、元数据、处理脚本及版本、参数与来源、数值设置、结果表、不确定度和失败记录。实验数据放`experiments/`或既有研究记录数据目录，计算放`simulations/`，计划与日志放`docs/研究记录/`，规程放`docs/实验指导/`。日常文档用Markdown；正式阶段报告按需另行生成。

本次修订不新增实测或重跑仿真；计划中的重复数和仪器量级是建议起点，预试验后根据离散度与时间尺度调整并记录理由。发布到`develop`前核对远端差异，逐项同步本次文档改动；既有未提交的实验分析与S8成果单独核对归档。

## 9. 首批执行清单

1. 核实E1上下界的同条件关系、有效板长与高差，确认是否存在滚动；补全样品与试次编号。

5. 验收同步链并复现至少一组虚线，先核实连续事件对应，再完成速度—载荷矩阵。
6. 同步推进S8独立观测标定与S9完整周期；冻结可辨识参数后开展S10留出验证。
