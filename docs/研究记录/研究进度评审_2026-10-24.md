## 四、P0：进入下一轮研究前应先补齐

### P0-1　回写模型适用边界，并同步文档版本

现有主模型和 S1—S3 的共同范围是：**固定铰轴的刚体转动、尖端罚弹簧接触、只计算 N 下降段，到分离事件即停止。**它不包含候选 A 的两个平动自由度，也没有完整包含候选 B 的轴向伸缩自由度；同时还没有上升段、自由飞行、再接触碰撞和多周期衔接。

因此，现有结果可以作为“固定铰轴、轴向自由度被冻结时的 N 下降段子模型”结果，但不能直接表述为：

- 两种候选手模型已经完成比较；
- 已经预测完整虚线周期、点距和自持条件；
- 已经由实验证明摩擦翻转、折叠峰或 LuGre 换向滞后。

**已核实的版本不同步：**

- 最新方案 Markdown 已有“两种候选并行”；
- 同名方案 DOCX 已含 E6A，但未包含这次手模型修正；
- 第一阶段搭建指导 PDF 的 E3 仍是单向弹性臂／手刚度标定口径；
- N 下降段模型报告和 S1—S3 结果说明尚未统一增加两候选背景下的退化模型声明。

**建议动作：**只补边界和版本，不篡改既有数值结果。所有文档使用同一段范围声明，并在 README 标明哪份文件是当前有效版本。

**验收标准：**任一读者从 README、方案 DOCX／Markdown、E3 手册或 S3 结果说明进入，都能看到一致的模型边界，不会把 S1—S3 误认为完整候选 A／B 或完整虚线模型。

### P0-2　建立参数—证据总表，优先落实实测标定

S1 已表明输出对接触刚度全程敏感，没有“取得足够大即可”的平台区；S3 的静摩擦比、Stribeck 速度和鬃毛参数仍有占位值；N₀、ω₀目前仍是人工指定的段间交接条件。继续提高积分精度不能替代这些输入。

建议建立一张总表，至少包含：

| 字段 | 内容 |
|---|---|
| 参数及唯一符号 | 区分接触、手模型、材料、几何、数值和观测参数 |
| 当前使用值与单位 | 明确是实测、文献、拟合、占位还是数值正则化参数 |
| 来源与日期 | 数据文件、文献或代码位置 |
| 负责实验 | E1、E2、E3、E4、E5、E6A 或新增动态摩擦实验 |
| 不确定度与适用工况 | 速度、载荷、角度、材料批次、温湿度、磨损状态 |
| 替换状态 | 哪些模型已使用实测值，哪些仍用占位值 |
| 可复现链接 | 原始数据、处理脚本、标定表和图 |

**验收标准：**至少形成一套完全可追溯的名义工况参数集；凡是仍占位的参数，在图题、结果表和结论中均有明确标记。

### P0-3　统一仿真与实验速度窗口

现有 S1—S3 名义板速为 **v = 0.5 m/s**；方案主装置为 **1–20 cm/s，即 0.01–0.20 m/s**，E2 为 **5–200 mm/s**。二者相差 2.5–50 倍，因此名义仿真曲线不能直接与未来实验数据逐点比较。

更重要的是，S2 的稳健窗口是特定 v 下的绝对 ε 窗口，不能原样迁移。例如名义 ε = 0.02 m/s：

- 在 v = 0.5 m/s 时，ε／v = 0.04；
- 在 v = 0.20 m/s 时，ε／v = 0.10；
- 在 v = 0.01 m/s 时，ε／v = 2.00，正则化反而比板速更大。

S2 已显示过大的 ε 会抹平切换，所以低速实验工况必须重新检查。LuGre 的 Stribeck 速度也应同时关注 v_s／v，而不是只沿用 v_s = 0.01 m/s 的占位值。

**建议动作：**旧 S1—S3 保留为历史结果并补适用条件；后续用于实验对照的计算直接在 E4 速度窗口内设置工况，以 ε／v、v_s／v 等无量纲量组织扫描和报告。

**验收标准：**每张实验—仿真对照图都具有相同的 v、几何、材料和交接条件，并明确本构参数来源；不再出现“直接把 0.5 m/s 名义结果当作 1–20 cm/s 装置预言”的情况。

### P0-4　先规定哪些量能用于实验检验

根据 S1—S3，建议把对照目标预先分级：

| 观测量 | 当前证据 | 实验使用建议 |
|---|---|---|
| N 下降段的存在、分离事件 | 在所测模型与参数区内成立 | 可作定性对照，但不能替代完整周期验证 |
| t* | S2 中较稳健；S3 跨本构约变化 −5%～−11%；但 S1 显示其明显依赖接触刚度 | 可用于联合标定与对照，必须同时给出刚度、N₀、ω₀和测量定义 |
| 两阶段图像、相对速度换向、摩擦翻转存在性 | 在 S2／S3 所测名义区跨本构较稳健 | 可作定性机制检验，仍需限定参数区 |
| t_flip 的绝对值 | LuGre 中比 tanh 提前约 25%～33% | 暂只作本构敏感量，不宜作为单一“判决实验” |
| I_2nd 绝对值 | 跨本构变化约 +28%～+52%，且不是实测粉尘质量 | 未标定观测模型前不作绝对灰度或沉积量对照 |
| 折叠峰绝对位置与微结构 | 峰位随本构移动，微结构受占位参数影响 | 暂作定性或探索性结果，不作为已验证定量预言 |
| 0.009–0.115 ms 力—速度换向滞后 | LuGre 占位参数下的新预言 | 只有在带宽、采样和同步达标后才可检验，否则应明确标为尚未具备测量条件 |

另外，S1 的 t* ∝ k_c^(−1/2) 是固定 N₀及其他条件下的渐近关系。**单独测一个 t* 不能在所有未知量同时存在时唯一反解接触刚度。**更稳妥的做法是用整段 N(t)、独立测得的 N₀和几何／运动学数据联合拟合，并报告参数相关性及置信区间。

**验收标准：**实验前写明主要终点、次要终点、允许误差和“不用于判决的量”，避免看到数据后再选择最吻合的指标。

## 五、P1：实验执行与数据解释需要补强

### P1-5　把“采样足够快”改成可验收的测量指标

方案已经要求检查量程、分辨率、带宽、采样率和安装刚度，但仍缺少数值目标。现有资料中的“≥10 kHz”不能覆盖全部已出现的仿真时间尺度：

- 10 kHz 的采样间隔为 0.1 ms；
- 240 fps 的帧间隔约 4.17 ms；
- 44.1 kHz 音频的采样间隔约 0.0227 ms；
- S1 扫描中最短 t* 约 0.0499 ms；
- S3 最短换向滞后约 0.009 ms，最长约 0.115 ms。

若仅按“每个目标过程至少有 10 个采样点”的起步设计估算：

| 测量目标 | 对应时间尺度 | 采样率起步估算 | 解释 |
|---|---:|---:|---|
| 黏滑周期、慢速夹持端运动 | 周期通常为 ms 以上 | 现有音频／视频可按任务使用 | 240 fps 适合慢相和整体运动学，不适合毫秒级卸载细节 |
| 覆盖 S1 最短卸载事件 | 0.0499 ms | 约 200 kS/s | 10 kHz 在该事件内不足一个采样间隔 |
| 分辨 S3 最长滞后 | 0.115 ms | 约 87 kS/s | 仍需传感器和安装结构具有相应动态响应 |
| 分辨 S3 最短滞后 | 0.009 ms | 约 1.11 MS/s | 还需微秒级同步；普通独立手机与 LED 对齐不足以承担该判决 |

这些数值只是根据目标时长得到的采集量级估算，**不等于只要提高 ADC 采样率就能完成测量**。力传感器自身带宽、安装共振、板下结构惯性、滤波群延迟、抗混叠和通道间时钟偏差都必须独立检查。

建议把 E5 拆成三个明确层级：

1. **周期与接触事件层：**声学通道负责周期和接触时刻，但需估计或标定声传播延迟，不将其称为未经校准的“精确时刻”。
2. **N(t) 卸载波形层：**按实际拟测 k_n 范围确定最短 t*，再用已知动态载荷、空载背景和安装刚度测试验证测量链。
3. **本构微小时差层：**使用同步采样的切向／法向力通道和共同时钟；若设备不能覆盖最短滞后，就把该目标降级为“当前不可检验”，而不是用欠采样数据给出肯定或否定结论。

**验收标准：**形成一张“目标时间尺度—传感器带宽—采样率—同步误差—滤波—可分辨结论”表，并用已知输入或独立事件验证，而不只引用仪器标称采样率。

### P1-6　E6A 需要区分准静态标定与动态反演

当前 E6A 的“多级稳定法向力、等长笔迹、稳定段强度”首先得到的是**准静态、笔画平均的 I–N 关系**。它不能直接证明：在毫秒级卸载过程中，每一个局部灰度都能通过同一曲线唯一还原瞬时 N(t)。

笔痕是接触力、接触时间、相对滑移距离、接触面积、磨损和沉积／脱附过程共同作用后的残留观测量。仿真的 I_2nd 是当前定义下的相对沉积／摩擦功代理，不是绝对粉尘质量，也不是相机灰度。

建议增加两道桥接：

- **动态验证：**用可重复的非恒定 N(t) 波形做标定外验证，比较准静态 I–N 反演与直接力测量；若不适用，就把 I–N 严格限定为平均或准静态反演。
- **正向观测模型：**先把模型输出的 N(t)、相对滑移和接触区间映射为预测笔痕，再与灰度比较。绝对灰度需要独立的沉积与光学响应标定；未完成前优先比较归一化形状和宏观特征。

**验收标准：**E6A 明确给出“能反演什么”——瞬时 N(t)、单点平均 N、整条笔画平均 N，或仅能判别接触／脱接触；任何反演都只在其经过独立验证的域内使用。

### P1-7　E1／E2 不能单独完成全部 LuGre 与率态参数辨识

E1 的 μ_s(t) 和 E2 的 μ_k(v) 是必要基础，但并不足以唯一给出所有动态本构参数：

- LuGre 的 σ₀、σ₁、σ₂涉及瞬态摩擦、鬃毛变形和阻尼，不能只靠静摩擦系数与稳态速度曲线确定；
- 标准率态临界刚度 k_crit = (b−a)N／D_c 中，稳态 μ_k(v) 斜率可约束速率依赖组合，但 D_c 仍需要独立的动态滑移信息；
- E1 的静置时间老化与滑移过程中的状态记忆不是可自动互换的标定量。

可增加速度阶跃、载荷阶跃、滑移—停止—再滑移或瞬态力—位移系统辨识实验，并将它们与 E5 的同步力／运动数据联合使用。如果暂时不做，应明确把 LuGre 和率态模型保留为**定性机制与趋势模型**，不宣称其定量参数已经全部标定。

**验收标准：**每个进入定量预言的本构参数都有独立数据约束；仅凭稳态曲线不能辨识的参数，报告其不可辨识性或模型依赖，而不是给唯一数值。

### P1-8　把 E3 新口径落实为操作手册和数据模板

第一阶段手册需要从“沿书写方向测一个手刚度”扩展为：

1. 两个正交方向分别加载，记录力、平动位移和转角；
2. 轴向拉压，记录轴向力—位移曲线；
3. 动态拨振或受迫响应，记录频率、阻尼和方向依赖；
4. 同一数据划分标定组与留出组，留出未参与标定的载荷方向、幅值和频率；
5. 候选 A、候选 B 使用相同输入和误差指标比较，同时报告参数置信区间与相关性；
6. 若两者误差接近、参数不可辨识或均有系统残差，结论写“暂不可判别”，并保留下一轮判别所需的新工况。

**验收标准：**手册包含装置图、加载方向、数据表字段、重复次数、数据处理脚本和留出判别示例，实验者不需要再从方案散文中自行拼出流程。

### P1-9　统一刚度符号

当前至少有三类不同物理量容易混用：

| 建议符号 | 物理含义 |
|---|---|
| k_n（或 κ_n） | 尖端法向接触的罚弹簧／等效接触刚度，即旧 S1—S3 中的 k_c |
| k_x、k_y、k_a 等 | 候选手模型或实验弹性臂的结构刚度 |
| k_crit | 率态稳定性中的临界刚度，即方案式（12）中的 k_c |

为避免破坏既有链接，旧文件名和旧结果表可暂时保留，但应增加“旧符号—新符号”映射；新代码、新图和新文档统一使用新符号。

**验收标准：**任一公式中的刚度都能从符号直接判断属于接触、结构还是稳定性阈值，不再共用无上下标的 k_c。
