## 1. 统一模型适用边界

现有主模型及 S1–S3 仅描述**固定铰轴、轴向自由度冻结、尖端罚弹簧接触的刚体棒在单周期 N 下降段**的退化子模型：法向力从人工交接值 N₀ 几何卸载至零，δ=0 分离即停止。它不包含上升段、自由飞行、再接触/碰撞和多周期映射，也不等同于候选 A（两个正交弹簧）或候选 B（自由轴加轴向弹簧）的完整手模型。

因此：

- S1–S3 的数值结果不是候选 A/B 的比较结果，不是完整虚线周期、点距或自持条件的预言；
- 摩擦翻转、折叠峰和 LuGre 换向滞后均为**数值预言**，尚无本仓库实验数据验证；
- N₀、ω₀是人工交接输入；接触刚度、摩擦与本构参数中的相应项仍为待标定值、文献参考值或占位值；
- S1 名义参数区未出现 Painlevé 型奇异，不排除其他 μ、h/L 或接触条件下的相关机制。

### 当前可追溯结论

目前可以追溯的是一套**名义数值工况**，而不是一套实测标定工况：固定铰轴几何、上述派生质量与转动惯量、k_n=2×10⁴ N/m、μ=0.35、v=0.5 m/s、ε=0.02 m/s、N₀=4 N、ω₀=0。凡涉及 k_n、N₀、ω₀、μ和 LuGre/率态参数的图表与结论，必须保留本表所列待标定或占位标记。

## 5. 观测量稳健性与实验使用分级

| 观测量 | 当前数值证据 | 实验使用建议 |
|---|---|---|
| N 下降段存在、分离事件 | 在所测模型与参数区内成立 | 可作定性对照，不能替代完整周期验证 |
| t* | S2 对 ε较稳健；S3 跨本构变化约 −5%～−11%；S1 显示明显依赖 k_n | 可用于联合标定；必须同时给出 k_n、N₀、ω₀、几何和事件定义 |
| 两阶段图像、相对速度换向、摩擦翻转存在性 | S2/S3 所测名义区跨本构较稳健 | 可作限定参数区的定性机制检验，不宣称实验已证实 |
| t_flip 绝对值 | LuGre 比 tanh 提前约 25%～33% | 本构敏感量，暂不作单一判决实验 |
| I₂nd 绝对值 | 跨本构变化约 +28%～+52%；且只是相对沉积/摩擦功代理 | 未完成 E6A 观测标定前，不作绝对灰度或沉积量对照 |
| 折叠峰绝对位置与微结构 | S3 峰位前移；微结构受占位参数影响 | 暂作定性/探索性结果，不作为已验证定量预言 |
| 力—速度换向滞后 0.009–0.115 ms | LuGre 占位参数下的新预言 | 只有带宽、采样、同步达标后才可检验，否则标为当前不可检验 |

**k_n 反演限制：**S1 的 t*∝k_n^(−1/2) 是固定 N₀及其他条件下的 fixed_N0 渐近关系。单独测一个 t* 不能在多个未知量同时存在时唯一反解 k_n。应使用整段 N(t)、独立测得的 N₀和几何/运动学数据联合拟合，并报告参数相关性及置信区间。

**E6A 反演限制：**准静态、笔画平均的 I–N 标定不自动适用于毫秒级瞬时 N(t) 反演。未完成非恒定 N(t) 动态验证和正向观测模型前，只能在经过独立验证的域内使用；零强度仅表示脱接触或低于检测限，不直接等价于 N=0。

## 6. 测量链目标与当前可检验性

以下为“每个目标过程至少约 10 个采样点”的起步量级估算，不等于只提高 ADC 采样率即可完成测量。传感器带宽、安装共振、结构惯性、滤波群延迟、抗混叠与通道时钟偏差须独立验证。

| 测量目标 | 时间尺度 | 采样率起步估算 | 当前口径 |
|---|---:|---:|---|
| 黏滑周期、慢速夹持端运动 | 通常 ms 以上 | 按周期与通道任务确定 | 声学/视频可用；240 fps 不适合毫秒级卸载细节 |
| 覆盖 S1 最短卸载事件 | 约 0.0499 ms | 约 200 kS/s | 原“≥10 kHz”不足一个采样间隔 |
| 分辨 S3 最长换向滞后 | 约 0.115 ms | 约 87 kS/s | 还需相应传感器与安装动态响应 |
| 分辨 S3 最短换向滞后 | 约 0.009 ms | 约 1.11 MS/s | 需微秒级同步；普通手机+LED 对齐不足，未具备条件前标为不可检验 |

声学通道可用于周期与接触事件，但需估计或标定声传播延迟，不称为未经校准的“精确时刻”。实验前应形成“目标时间尺度—传感器带宽—采样率—同步误差—滤波—可分辨结论”记录表，并预先指定主要终点、次要终点及不用于判决的敏感量。
