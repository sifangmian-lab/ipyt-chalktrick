# 本地工作区同步说明

本次仅在 `develop` 增加同步配置，没有合并分支，也没有改动既有研究模型、实验数据或结论。

## 同步方式

仓库新增 `code/tools/sync_workspace.ps1`，默认本地路径为 `D:\vibelab\iypt`，默认分支为 `develop`。脚本行为如下：

1. 目标目录不存在时，克隆 `develop` 到该目录。
2. 目标目录已经是本项目工作区时，获取远端更新并执行快进同步。
3. 目标目录存在无关文件、远程仓库不匹配、本地修改阻碍切换或分支发生分歧时，停止并提示，不强制覆盖。
4. 不自动提交或推送本地修改，不保存 GitHub 令牌。

首次若尚未克隆仓库，可在 Windows PowerShell 执行：

```powershell
git clone --branch develop https://github.com/sifangmian-lab/ipyt-chalktrick.git D:\vibelab\iypt
```

以后从远端同步到本地，可执行：

```powershell
powershell -ExecutionPolicy Bypass -File D:\vibelab\iypt\code\tools\sync_workspace.ps1
```

如需显式指定路径或分支：

```powershell
powershell -ExecutionPolicy Bypass -File D:\vibelab\iypt\code\tools\sync_workspace.ps1 -LocalPath 'D:\vibelab\iypt' -Branch 'develop'
```

本地修改需要同步回 GitHub 时，应先检查、提交，再推送：

```powershell
git -C D:\vibelab\iypt status
git -C D:\vibelab\iypt add .
git -C D:\vibelab\iypt commit -m "更新本地研究工作区"
git -C D:\vibelab\iypt push origin develop
```

## 权限边界与完成状态

当前 agent 运行在独立的 Linux 沙箱中，不能直接访问或控制用户 Windows 电脑的 `D:` 盘。因此，本次能够完成的是远端脚本和配置记录；**本地目录是否已创建及是否同步成功，只能以该脚本在用户电脑上的实际运行结果为准**。

认证交给 Git 凭据管理器处理。不要把令牌写进脚本、远程 URL、文档或提交信息。
