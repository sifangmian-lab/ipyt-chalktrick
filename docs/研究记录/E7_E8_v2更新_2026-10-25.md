## 1. E7：反演链更新

### 1.1 原则

- 仍然采用“知三推一”：固定三个参数，反演第四个；多通道交叉给出置信度；
- **模型依赖必须显式**：同一个痕迹在 v1 与 v2 下可能给出不同参数；v2 未标定前不报告唯一“手刚度”；
- 只在经过独立验证的域内反演；零强度 = 脱接触 / 滑移停止 / 低于检测限，不能自动当作 $N=0$；
- 报告不确定度（标定、统计、模型误差）与参数相关性。

### 1.2 反演量（v2 增补）

| 可观测量 | 途径 | 目标参数 | 依赖 | 备注 |
|---|---|---|---|---|
| 点距 $p$、周期 $T$ | $v=p/T$（声学） | $v$ | E5/E6 | 最稳健 |
| 点长 $s$、空白 $g$ | 几何 + v2 滑移/跳跃模型 | $v$、$N_0$、$k_x/k_y$ | E4–E6 | v2 下需模型 |
| 线宽 $w$ | $w=2r$ + 磨损修正 | 粉笔直径/磨损 | E6/T3d | 保留 |
| 平台强度 $I_{\rm plateau}$ | v2 $I=\alpha\mu N$ | $N$ 或 $\mu$ | E6A | 需沉积标定 |
| 截断强度 $I_c$、截断位置 $\xi_c$ | stop point / 黏着判据 | $k_x/k_y$、$\mu_s$、$v$ | E5/E6A | v2 新反演目标 |
| 截断平台比 $R_c=I_c/I_{\rm plateau}$ | 平台+截断 vs 下降尾 | 摩擦本构（$\mu_s/\mu_k$、$\sigma_{1,2}$）或手端柔度 | E1/E2/E5 | 模型判别量 |
| 折叠尖峰/回划尾 | v1 特有 | — | — | **v2 下不作为主反演目标**；若观察到需单独讨论 |

### 1.3 盲反演流程（E7 更新）

1. A 组秘密设定 $(v,\alpha,N_0,k_x/k_y,\text{粉笔直径})$，画线并记录力/图像；
2. B 组仅用 E6 轮廓 + E5 声学 + E3 标定库反演；先反演 $v$、$p$、$w$，再反演 $I_{\rm plateau}$/$\xi_c$；
3. 报告每个参数的点估计 + 区间 + 模型依赖（v1/v2 分别给结果，若差异大则说明模型未定）；
4. 评分：相对误差 + 区间覆盖率；对“模型不可判别”的工况单独列出，不强行给唯一值。

### 1.4 验收标准

- [ ] 反演表每一行注明依赖模型（v1/v2）与有效域；
- [ ] 至少 1 组 v2 盲反演：$\xi_c$ 或 $R_c$ 的预测落在实验区间内；
- [ ] 若 v1/v2 反演结果差异超过实验误差，报告模型依赖而不是选一个“更好看”的；
- [ ] 参数相关性矩阵与不确定度预算随结果一起报告。

## 2. E8：普遍性更新

### 2.1 从“是否出虚线”升级为“痕端形态是否同构”

原 E8 只判定各材料—表面组合是否出现周期性点列。v2 后应增加：

- 是否出现**平台 + 有限强度截断**的轮廓（$R_c$、$S_c$）；
- 痕端事件类型（黏着/脱离/冲击，E5 判定）；
- 同样的无量纲组下，不同材料是否落在同一“平台+截断”区域。

### 2.2 材料矩阵（保留 + 增补）

| 书写材料 | 表面 | 预期机制 | 观察重点 |
|---|---|---|---|
| 石膏粉笔 | 黑板 | 干摩擦 + 粉粒沉积 | 基线：平台+截断？点距/强度 |
| 无尘碳酸钙粉笔 | 黑板 | 干摩擦，磨损不同 | 磨损/截断形态 |
| 铅笔（石墨） | 纸/黑板 | 黏附—剥离 | 是否有点列/强度轮廓 |
| 蜡笔 | 纸/黑板 | 塑性变形/黏附 | 与干摩擦差异 |
| 白板马克笔 | 白板 | 油墨毛细/挥发 | 负结果及机制差异 |
| 其他（粉笔） | 玻璃/粗糙面 | 接触刚度变化 | 平台/截断随表面变化 |

### 2.3 无量纲组（v2 版）

$$
\frac{k_x}{k_y},\quad \frac{k_yL}{mg},\quad \frac{k_\theta}{k_yL^2},\quad
\frac{mv^2}{k_yL^2},\quad \mu_s,\ \mu_k,\ \frac{\mu_s}{\mu_k},\quad \theta_0
$$

E8 的目标不是比原始参数，而是检验不同材料在以上无量纲平面上的“平台+截断”边界是否重合。

### 2.4 验收标准

- [ ] 至少 2–3 组材料给出可比较的 $I(\xi)$ 轮廓与 $R_c$；
- [ ] 负结果（如马克笔不出点列）记录并解释机制差异；
- [ ] 给出无量纲平面上的落点与边界草图；
- [ ] 明确“不同沉积机制”限制了哪些结论，不把粉笔的摩擦学结论直接外推到油墨体系。
