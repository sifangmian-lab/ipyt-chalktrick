## 1. 项目目标与当前边界

### 1.1 研究对象

研究粉笔在黑板上持续运动时形成断续虚线的机制，主要涉及：

- 黏滑（stick-slip）自激振荡；
- 弹性储能、摩擦失稳与接触几何耦合；
- 离面跃起、碰撞、sprag-slip 与 Painlevé 悖论；
- 虚线节距、痕迹强度随板速、倾角、载荷、系统刚度和摩擦本构的变化；
- 最终由痕迹反演运动参数的可能性与适定性。

直接赛题背景应优先写作 **IPT 2023 “The Chalk Trick”**。不要在未重新核实前写成“IYPT 正式赛题”。

### 1.2 当前模型只覆盖一个片段

现阶段主模型是**单周期黏滑循环中滑移事件的后半段，即法向力 $N$ 的下降段**：

- 粉笔视为绕固定轴 $O$ 转动的自由轴刚体棒；
- 板面接触用罚弹簧表示；
- 法向力从交接值 $N_0$ 降至零，$\delta=0$ 时终止；
- 可发生相对速度换向和摩擦力翻转；
- 输出分离时间、相对笔痕强度及其空间分布。

**尚未构成完整虚线模型**：上升段、自由飞行段、再次接触/碰撞、多周期映射、自持条件和实线—虚线整体相图仍未闭合。

## 4. 当前模型的最小技术上下文

### 4.1 基本定义

接触压入量、法向力和相对速度为：

$$
\delta=L\cos\theta-h,\qquad N=k_c\max(\delta,0),
$$

$$
v_{\mathrm{rel}}=v-L\cos\theta\,\dot\theta.
$$

采用 tanh 正则化库仑摩擦时，转动方程为：

$$
I_O\ddot\theta
=N\left(L\sin\theta+\mu h\tanh\frac{v_{\mathrm{rel}}}{\varepsilon}\right)
-\frac{mgL}{2}\sin\theta,
\qquad I_O=\frac{mL^2}{3}.
$$

初始角和分离角由几何关系给出：

$$
\theta_0=\arccos\frac{h+N_0/k_c}{L},
\qquad
\theta_*=\arccos\frac{h}{L}.
$$

主要输出包括：

$$
t^*,\qquad t_{\mathrm{flip}},\qquad
I_{2\mathrm{nd}}=\mu\int_0^{t^*}N|v_{\mathrm{rel}}|\,dt,
\qquad
\ell=\int_0^{t^*}|v_{\mathrm{rel}}|\,dt.
$$

空间痕迹通过 $\xi(t)=\int v_{\mathrm{rel}}dt$ 映射；若发生回划，同一 $\xi$ 上的贡献需要折叠求和。

### 4.2 名义参数

| 参数 | 当前名义值 | 备注 |
|---|---:|---|
| $L$ | $0.08\ \mathrm{m}$ | 粉笔长度 |
| $h$ | $0.075\ \mathrm{m}$ | 轴到板面距离 |
| $r$ | $3.5\times10^{-3}\ \mathrm{m}$ | 粉笔半径 |
| $\rho$ | $2300\ \mathrm{kg/m^3}$ | 密度设定 |
| $\mu$ | $0.35$ | 当前模型值，不是普适实测常数 |
| $k_c$ | $2.0\times10^4\ \mathrm{N/m}$ | 待实验标定 |
| $v$ | $0.5\ \mathrm{m/s}$ | 板速 |
| $\varepsilon$ | $0.02\ \mathrm{m/s}$ | tanh 正则化尺度 |
| 名义交接条件 | $N_0=4\ \mathrm{N},\ \omega_0=0$ | 当前是输入，不是自洽模型输出 |

### 4.3 不要误解这些量

- $N_0,\omega_0$ 是前半段与本段之间的**交接参数**，目前由人工指定；完整模型应由上升段导出它们。
- $I_{2\mathrm{nd}}$ 是按当前定义计算的**相对沉积/笔痕指标**，不能直接解释为真实粉尘质量或实验能耗。要得到绝对沉积量，需要额外标定沉积系数并建立实验对应。
- 文献综述中其他报告的摩擦系数、当前代码中的 $\mu=0.35$、S3 中的占位 $\mu_s$ 不是一组已完成统一标定的数据，不要混用。

## 5. 已完成的数值工作

| 工作 | 设置与结果 | 对后续工作的约束 |
|---|---|---|
| **S1：$k_c$ 刚性极限收敛扫描** | 扫描 $k_c=10^3\sim10^7\ \mathrm{N/m}$，含 `fixed_N0` 与 `fixed_delta0` 两种模式、双容差复算。当前参数区未见 Painlevé 型奇异；输出对 $k_c$ 全程敏感，无“足够大即可”的平台区。 | $k_c$ 必须标定。固定 $N_0$ 时，大 $k_c$ 段有 $t^*\propto k_c^{-1/2}$ 标度。摩擦翻转并非所有刚度下都存在。 |
| **S2：$\varepsilon$ 灵敏度扫描** | $\varepsilon=10^{-4}\sim10^0\ \mathrm{m/s}$。名义工况下，$10^{-3}\sim10^{-1}\ \mathrm{m/s}$ 为较稳健窗口；大 $\varepsilon$ 会抹平切换。$t^*$ 对 $\varepsilon$ 相对不敏感，折叠峰位置较稳健、峰形较敏感。 | 推荐工作包线：$k_c\in[10^4,2\times10^4]\ \mathrm{N/m}$，$\varepsilon\in[10^{-3},5\times10^{-2}]\ \mathrm{m/s}$。不要在翻转存在边界附近做精细定量预言。 |
| **S3：LuGre 本构对比** | 用 LuGre 替换 tanh。翻转仍出现，但在测试组中比 tanh 早约 $25\%\sim33\%$；$t^*$ 变化约 $-5\%\sim-11\%$，$I_{2\mathrm{nd}}$ 增加约 $28\%\sim52\%$。摩擦力换向晚于速度换向，出现约 $0.009\sim0.115\ \mathrm{ms}$ 的滞后。 | 定性图像跨本构较稳健；翻转时刻、绝对强度和折叠峰位置仍依赖本构与参数。$\mu_s=1.15\mu_k$ 是占位设定，E1 数据到位后必须替换。 |

### S3 的数值警告

`σ₀=1e5、σ₁=100` 这一组曾出现约 49 ms 的双容差差异，处于刚性振荡区，**该点细节数值不可信，只能看趋势**。不要把它作为定量结论引用。S3 的其他数值经验和掩膜处理详见其结果说明与源码。

## 6. 结论可信度分级

### 6.1 可以写，但必须带适用条件

- 在 S1 已扫描的参数范围内，罚弹簧模型未显示 Painlevé 型奇异；这不等于排除其他参数区的 Painlevé 机制。
- $t^*$ 是目前较鲁棒的输出，但仍明显依赖 $k_c$，可用于设计标定实验，不能脱离 $k_c$ 给出普适数值。
- 在 S2/S3 已测试的名义工况附近，两阶段图像、相对速度换向和摩擦翻转不是单纯的 tanh 数值伪影。
- LuGre 给出了可检验的换向滞后预言，但滞后大小依赖占位参数，当前主要用于提出实验判别目标。

### 6.2 暂时不能写成定论

- “粉笔虚线已经完全由当前单段模型解释。”

### 7.2 两条可并行的高价值支线

**数值支线：S4 参数平面扩展。**扫描 $(\mu,h/L)\times k_c$，寻找 $t^*$ 的振荡、跳变或失稳边界。S1 名义点的力臂比 $\mu h/(L\sin\theta_*)\approx0.943$，接近临界值 1，值得检查更高 $\mu$ 或 $h/L$ 区域。若触发奇异，再考虑 LCP、碰撞律或 reverse-chatter 路线。

**实验支线：E1 + E4 标定。**E1 提供 $\mu_s$ 及时间老化信息；E4 测 $N(t)$ 卸载过程并反标 $k_c$。S1 给出的 $\ge10\ \mathrm{kHz}$ 是测量 $t^*$ 的最低建议；若要分辨 S3 的 $0.01\sim0.1\ \mathrm{ms}$ 换向滞后，需要按目标时间分辨率重新设计更高的采样率和同步切向力测量，不能直接沿用该最低值。

### 7.3 完整周期与机制判别

- 拼接自由段与再次接触/碰撞规则，建立多周期映射。
- 用稳定性与分岔语言研究实线/虚线边界、自持条件和双稳区。
- 用高速摄影直接观察离面位移，区分纯切向黏滑与 sprag-slip / hopping 的相对贡献。
- 设计板速先升后降的扫描，检查转变速度的迟滞。
- 将力、声学和图像时间戳同步，避免只凭最终痕迹反推机制。

## 11. 新文件分类与 GitHub 提交规范

所有生成的交付物必须按内容分类归档，不要堆在仓库根目录：

| 新产出 | 应放位置 |
|---|---|
| 阶段计划、研究笔记、交接文档 | `docs/研究记录/` |
| 综述、译稿、论文式文档 | `docs/文献综述/` 或按内容新建清晰的 `docs/` 子目录 |

| 建模报告 | `docs/模型报告/` |

| PDF/字体等辅助构建工具 | `code/tools/`、`assets/` |

3. 一次提交尽量包含同一任务的代码、数据、图和结果说明，提交信息概括研究内容。
4. 上传后重新读取远端路径，确认文件存在且内容完整。
5. 最终回复同时说明本地交付文件和远端归档位置。
6. `__pycache__/`、`*.pyc`、`eq_tex/`、系统缓存等临时产物不提交；不要把访问令牌写入任何文件。
