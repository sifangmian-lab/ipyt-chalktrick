# E3 扩展规程：正交柔度模块与杆/手端标定（2026-10-25）

> 目的：为 v2 模型（弹性杆 + 手端正交弹簧）提供可辨识的 $k_x,k_y,k_\theta$（或 $EI$）与阻尼，并区分“装置柔度”与“人手柔度”。  
> 关联：`docs/研究记录/模型v2规格_2026-10-25.md`、`simulations/S4_v2正交弹簧基线/结果说明.md`、`simulations/S6_v2参数平面/结果说明.md`。  
> 状态：**设计/规程**，待加工与执行；当前仓库无 E3 实测数据。

## 1. 需要测什么（区分两套系统）

| 系统 | 用途 | 需要参数 |
|---|---|---|
| **装置柔度**（E4 主装置：龙门架 → 弹性臂 → 粉笔夹持） | 进入 E4/E5/E6 的 v2 模型，解释“平台+截断” | $k_x,k_y,k_\theta$（或 $EI$）、$c_x,c_y$、几何/质量、角度 |
| **人手柔度**（真人手绘对照） | E7/E8 与手绘比较，不能与装置参数混用 | 两向平移、转动/弯曲、阻尼、随握力的变化 |

> 关键：v2 模型的“正交弹簧”指的是**从固定支架到杆端/笔夹持的等效柔度**。若装置本身是一根硅胶悬臂梁，则它的弯曲/压缩刚度就是 $k_x,k_y,k_\theta$ 的来源，而不是另一个人手模型。两条路径必须分别标定，不能把“手刚度 1.74 N/cm”直接搬进装置模型。

## 2. 可更换正交柔度模块（装置改造建议）

目标：让 E4 可以在已知 $k_x,k_y$ 下工作，从而直接检验 S6 的“平台+截断”参数区。

```
龙门支架
  └─ 二维柔度模块：x 向片簧 + y 向片簧（可更换刀片/配重）
       └─ 角度调节夹头（记录 α）
            └─ 粉笔/弹性臂
```

- **x 向（切向）**：片簧悬臂，$k_x=3EI_x/L_x^3$，通过更换刀片厚度/长度调 $k_x$；
- **y 向（法向）**：独立的片簧/压缩弹簧，调 $k_y$；建议 $k_y\gg k_x$（对应 S6 的“平台”区）；
- **转动/弯曲**：夹头与粉笔之间保留可测的 $k_\theta$，可用不同长度的粉笔/弹性臂改变；
- **阻尼**：可在片簧端加薄油膜/橡胶垫，但需测 $c_x,c_y$（否则 S4 的振铃会被误当物理）；
- **设计目标区间**（来自 S6 与粉笔弯曲估算）：$k_x=10^2$–$3\times10^3$ N/m，$k_y=10^5$–$10^6$ N/m，$k_\theta=10$–$3\times10^3$ N·m/rad（或 $EI=0.02$–$0.6$ N·m²）；
- 结构要求：模块本身的一阶共振频率应显著高于目标事件频率；所有连接处不得有未标定的间隙/摩擦。

## 3. 静态标定规程

1. **加载**：在笔尖/夹头处沿 $+x,-x,+y,-y$ 分别加 5–7 级已知力（砝码/拉力计），记录位移（百分表/激光位移计）与转角（镜面/双位移计）；
2. **重复**：每级 ≥3 次，加载/卸载各一遍，检查滞回；
3. **拟合**：用线性/弱非线性模型拟合
   $$
   \begin{bmatrix}F_x\\F_y\\M\end{bmatrix}
   =\begin{bmatrix}k_{xx}&k_{xy}&k_{x\theta}\\k_{yx}&k_{yy}&k_{y\theta}\\k_{\theta x}&k_{\theta y}&k_{\theta\theta}\end{bmatrix}
   \begin{bmatrix}u_x\\u_y\\\theta\end{bmatrix},
   $$
   报告对角线 $k_x,k_y,k_\theta$ 与交叉项（若交叉项 >20% 主项，v2 需升级耦合模型）；
4. **留出验证**：用未参与拟合的方向/幅值/加载点检验预测；
5. **不确定度**：给出每参数的置信区间、重复性、温湿度与夹持状态记录。

## 4. 动态标定规程

- 拨动/阶跃释放，记录端部位移衰减：由对数减幅得 $\zeta$，由自由振动频率得等效刚度与质量；
- 若可做受迫扫频（压电/电磁激励 + 加速度计），给出一阶频率与相位；
- 与静态刚度互验；若动态刚度显著高于静态，检查间隙/预紧/夹持。

## 5. 粉笔/弹性臂的 $EI$ 与 $k_\theta$

- 对粉笔：三点弯曲或悬臂加载，测 $EI$（预期 $E\sim2$–3 GPa、$r=3.5$ mm、$L=0.08$ m → $EI\sim0.24$–$0.35$ N·m²，$k_\theta=3EI/L\sim9$–13 N·m/rad）；
- 对硅胶弹性臂：同样测 $EI$；注意其几何非线性与黏弹性（做加载速率依赖）；
- **重要：**S4/S6 中的 $k_\theta=100$–3000 N·m/rad 是“等效硬转动”的占位值；若实际粉笔只有约 10 N·m/rad，需要补 S6b（$k_\theta=1$–30）确认是否仍能形成平台+截断——这是 E3 数据到位后的第一批仿真。

## 6. 输出与验收

| 产出 | 验收标准 |
|---|---|
| 参数表 | $k_x,k_y,k_\theta$（或 $EI$）、$c_x,c_y$、$\zeta$、交叉项、置信区间齐全 |
| 数据与脚本 | 原始力—位移/时间序列、处理脚本、重复次数、留出验证 |
| 模型对接 | 将标定值代入 S4/S6，报告“平台+截断”区域是否与 E4 观察一致 |
| 判别 | 若 $k_y$ 或 $k_\theta$ 与 S6 目标区相差 >5 倍，先不要用当前 v2 做定量预言 |

## 7. 数据表字段（建议）

`工况ID, 方向, 加载级, 力/N, 位移/mm, 转角/rad, 加载/卸载, 重复号, 温度, 湿度, 夹持状态, 备注`；动态数据另加 `采样率, 滤波, 激励方式`。

## 8. 与 E4/E5/E6A 的接口

- E3 给出 $k_x,k_y,k_\theta$ 后，S4/S6 才能把“平台+截断区”映射到实际装置；
- E4 应在至少 2–3 组已知 $(k_x,k_y)$ 下画线，记录痕端形态；
- E5 同步测 $N(t)$、$v_{\rm rel}(t)$，检验 stop point（$v_{\rm rel}\to0$、$N$ 有限）；
- E6A 的截断判据见 `docs/实验指导/E6A截断判据执行清单_2026-10-25.md`。
