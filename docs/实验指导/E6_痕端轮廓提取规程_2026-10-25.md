# E6 扩展：痕端轮廓提取规程（2026-10-25）

> 目的：从原始灰度图像中提取**逐划痕的强度轮廓 $I(\xi)$** 与痕端指标，避免只给平均强度或二值化几何量。  
> 关联：`E6A截断判据执行清单_2026-10-25.md`、`E5_痕端事件测量链_2026-10-25.md`、`code/deposit_profile.py`。  
> 状态：规程；待图像数据。

## 1. 采集要求

- 固定照明、白平衡、曝光、拍摄距离；保留原始灰度（RAW/PNG），不要只存二值化图；
- 每张图带标定尺/网格（像素→mm）；
- 对同一工况至少 3 个曝光档（正常/欠曝/过曝各 1 档），用于阈值鲁棒性；
- 记录粉笔批次、磨损状态、板面跑道、温湿度；
- 图像与 E5 的力/声学数据用共同触发或至少同一时间基准。

## 2. 预处理

1. 几何校正（透视/镜头畸变）；
2. 平场校正：用同一照明下的空白板图像做背景扣除；
3. 沿笔画方向取中心线（可用骨架化/手工两点连线），垂直方向取灰度剖面；
4. 对每条笔画生成 $\xi$（沿笔画坐标）与 $I(\xi)$（扣背景后的灰度/光密度）。

## 3. 痕端指标（与 E6A 一致）

| 指标 | 定义 | 用途 |
|---|---|---|
| $I_{\rm plateau}$ | 笔画中段（20%–80%）强度中位数 | 平台强度 |
| $I_c$ | 痕端前最后 5% 的平均强度 | 截断强度 |
| $\xi_c$ | 痕端位置（沿笔画坐标） | 截断位置 |
| $R_c=I_c/I_{\rm plateau}$ | 截断平台比 | 判断“有限强度截断” |
| $S_c$ | 痕端归一化斜率 $\dfrac{|\Delta I/\Delta\xi|_{\rm end}}{I_{\rm plateau}/\ell}$ | 截断锐度 |
| $w(x)$ | 半高宽沿 $\xi$ | 线宽/磨损 |
| 阈值/曝光位移 | 换阈值/曝光后 $\xi_c,I_c$ 的变化 | 排除表观截断 |

判读：
- $R_c\lesssim0.1$ 且 $I_c$ 接近背景噪声 → 更可能是**衰减到零**（或表观截断）；
- $R_c$ 接近 1 且 $\xi_c,I_c$ 对阈值/曝光稳定 → **有限强度截断**；
- 若 $R_c$ 稳定但 $\xi_c$ 随阈值移动 → 优先怀疑图像/照明问题。

## 4. 实现步骤（建议脚本接口）

```
输入：原始图像、标定尺、笔画中心线（或自动骨架）
输出：profile.csv（xi_mm, intensity, fwhm_mm）、metrics.json（I_plateau, I_c, R_c, S_c, xi_c）
```

- 平滑：沿 $\xi$ 做轻度高斯平滑（σ≈1–2 像素或等价长度），报告平滑参数；
- 强度归一化：用平台中位数归一化，禁止用单点峰值；
- 每条笔画至少 30 个采样点；每个工况 ≥30 条笔画，给出分布而非均值；
- 二值化图只用于几何量（点距、点长、空白、宽度），不得用于强度。

## 5. 验收标准

- [ ] 同一划痕在 3 个曝光档下 $I_{\rm plateau}$、$R_c$ 的相对差 <20%；
- [ ] 阈值从 0.3–0.7 倍背景变化时 $\xi_c$ 移动 <1 像素或 <5% 点长；
- [ ] 每条笔画输出完整 `profile.csv` + `metrics.json`；
- [ ] 至少 2 个工况的 $R_c$ 分布可区分“平台+截断”与“下降尾”；
- [ ] 与 E5 的 stop point/lift-off 时刻对齐后，能说明强度截断对应哪类事件。

## 6. 与 v2 模型的对照方式

- 将模型输出 $I(\xi)$ 与实测轮廓**按平台强度归一化**后比较形状，不先比较绝对灰度；
- 比较 $R_c$、$\xi_c/\ell$、$S_c$ 与平台段长度；
- 模型侧统一用 `code/deposit_profile.py`（权重 $q\,dt$），保证 $\int I\,d\xi=I_{2\mathrm{nd}}$；
- 绝对灰度/沉积量需要独立的沉积—光学标定，未完成前不做绝对强度结论。

## 7. 与 E6A 的分工

E6 负责“如何从图像得到轮廓与指标”；E6A 负责“截断是否真实、属于哪类机制”的判定与实验设计。两者共用 §3 的指标定义，避免各写一套。
