# E6A 截断判据执行清单（P0-1）

> 日期：2026-10-25  
> 目的：把“笔痕强度在有限值处截断”从观察升级为**可判定的实验事实**，并区分三类机制：黏着截断（$v_{\mathrm{rel}}\to0$，$N$ 仍有限）、动力脱离（$N\to0$）、sprag-slip/撞击（有限 $N$ 下跳起/冲击）。  
> 状态：**待数据执行**。当前仓库没有 E1/E4/E6A 原始图像或力数据，本清单先把判据、数据表与通过标准固定下来；有数据后即可逐项执行。

## 1. 判定原则

必须同时回答两个问题：

1. **截断是不是真的？**（不是二值化阈值、照明/灰度饱和、磨损或图像压缩造成的表观截断）
2. **如果是真的，是哪种机制？**（黏着 / 脱离 / 跳跃）

> 关键提醒：**零强度 ≠ $N=0$**。若笔尖相对板面停止滑动（黏着），即使法向力仍为有限值，也不再有新沉积。因此“强度截断”不能自动解释为“接触力归零”。

## 2. 所需原始数据（每条笔画）

| 数据 | 要求 | 现状 |
|---|---|---|
| 原始灰度图像 | 固定照明/曝光/拍摄距离；保留未二值化原图；含标定尺 | 仓库中无 |
| 法向力 $N(t)$ | 与图像同一时间基准；带宽/采样率满足痕端事件（先按 ≤0.1 ms 量级设计，最终由 S4/S5 定） | 仓库中无 |
| 切向力/摩擦信号 | 与 $N(t)$ 同步；用于判断滑移/黏着 | 仓库中无 |
| 离面/位移视频 | 侧拍痕端；帧率足够判“抬起”还是“停住” | 仓库中无 |
| 声学通道 | 接触/冲击时刻；需标定声传播延迟 | 可有（手机 44.1 kHz） |
| 工况元数据 | $v$、$N_0$、接触角、$k_x/k_y$ 装置配置、粉笔批次/磨损、温湿度 | 待补 |

## 3. 执行步骤

### 步骤 1：逐划痕强度轮廓
- 对每条笔画取垂直于笔画的灰度剖面，扣除背景并做照明校正；
- 沿笔画方向得到 $I(\xi)$（$\xi$ 为沿笔画坐标），而不是只用整条笔画平均灰度；
- 记录平台强度 $I_{\mathrm{plateau}}$、痕端前最后可测强度 $I_c$、截断位置 $\xi_c$；
- 定义截断锐度
  $$
  S_c=\frac{|dI/d\xi|_{\text{痕端}}}{\max(I)/\ell_{\text{笔画}}}
  $$
  或等价的无量纲量（在报告中固定一种定义）。

### 步骤 2：阈值/曝光鲁棒性（排除表观截断）
- 至少取 3 个二值化阈值、3 档曝光，重复步骤 1；
- **判定：** 若 $\xi_c$、$I_c$ 随阈值/曝光显著移动，或截断前强度已接近背景噪声（$<3\sigma$），则优先判为**表观截断**，记录并停止据此改模型；
- 只有 $\xi_c$、$I_c$ 在阈值/曝光变化下稳定，才进入步骤 3。

### 步骤 3：与力/运动对齐（区分机制）
- 将痕端时刻与同步的 $N(t)$、$F_f(t)$、$v_{\mathrm{rel}}(t)$、离面位移对齐；
- 判据表：

| 观察 | 机制 | 模型出口 |
|---|---|---|
| 痕端 $N$ 仍有限；$v_{\mathrm{rel}}\to0$；无撞击声 | **黏着截断** | 切向弹簧/状态摩擦的黏着解；$I(\xi)$ 在有限 $N$ 处台阶 |
| 痕端 $N$ 快速降到 0；有离面位移/声学脉冲 | **动力脱离** | 单边接触 + 法向动力学；$N\to0$ 的时间尺度远小于沉积尺度 |
| 痕端 $N$ 突变、明显跳起/冲击、周期含飞行相 | **sprag-slip/反向颤振** | LCP/冲击律或足够刚的接触；需恢复系数/碰撞律 |
| $N$ 与 $v_{\mathrm{rel}}$ 都无明显变化，仅灰度下降 | 观测/沉积律问题（磨损、饱和、离焦） | 先修观测模型，不归因于接触动力学 |

### 步骤 4：可重复性
- 每工况 ≥30 条笔画；报告 $I_c$、$N_c$（若可测）、$\xi_c$ 的批内/批间离散度；
- 若 $I_c$ 或 $N_c$ 的批间离散度大于工况间差异，不能用于模型判别。

### 步骤 5：条件依赖（模型判别）
- 改变手端柔度 $k_x/k_y$（若装置已加正交柔度模块）、$N_0$、$v$、磨损状态，重复步骤 1–4；
- 若截断位置/强度随 $k_x/k_y$ 系统性移动，支持**力学截断**；
- 若几乎不随柔度变化而只随灰度/材料变化，优先怀疑观测/沉积律。

### 步骤 6：通过标准（写入结果表）
- [ ] 多阈值/多曝光下 $\xi_c$、$I_c$ 稳定（判为真实截断）；
- [ ] 痕端事件类型可唯一判为 stick / lift-off / impact；
- [ ] $I_c$、$N_c$、$\xi_c$ 的重复性满足预设阈值（建议相对标准差 <20%，按装置实际调整）；
- [ ] 至少 2–3 个工况的截断随柔度/载荷变化趋势与 v2 模型一致；
- [ ] 若未通过，明确记录“表观截断/不可判定/数据不足”，不据此改模型。

## 5. 与模型/文档的接口

- 判据判为“真实截断”后，S4 的验收目标改为“平台 + 有限强度截断 + 正确的痕端事件类型”；
- 若判为“黏着截断”，v2 必须能给出 $v_{\mathrm{rel}}\to0$ 且 $N>0$ 的解；
- 若判为“动力脱离/跳跃”，v2 必须引入单边接触/冲击律并检查恢复系数敏感性；
