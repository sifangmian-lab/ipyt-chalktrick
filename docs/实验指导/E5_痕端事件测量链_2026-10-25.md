# E5 扩展：痕端事件测量链（2026-10-25）

> 目的：把 E5 从“测 $N(t)$、$t_{\rm stick}$、$t_{\rm flight}$”升级为**能判定痕端事件类型**的同步测量：  
> 黏着截断（$v_{\rm rel}\to0$、$N$ 有限） / 动力脱离（$N\to0$、离面） / sprag-slip 冲击（$N$ 突变、撞击声、离面）。  
> 关联：`E6A截断判据执行清单_2026-10-25.md`、`simulations/S4_v2正交弹簧基线/结果说明.md`、`simulations/S5_v2收敛性/结果说明.md`。  
> 状态：规程；待装置与数据。

## 1. 需要同步的通道

| 通道 | 测什么 | 关键要求 |
|---|---|---|
| 法向力 $N(t)$ | 痕端处 $N$ 是否降为 0 | 量程覆盖 0.1–20 N；分辨率 ≤0.01 N；带宽 ≥20 kHz；采样 ≥100 kS/s（见 §2） |
| 切向力/摩擦 $F_f(t)$ | 滑移→黏着、摩擦换向 | 与 $N$ 同带宽；安装刚度足够高，避免传感器改变接触动力学 |
| 运动学 $v_{\rm rel}(t)$ | 停点、离面位移 | 高速摄影/激光测振；至少能判“停住”与“抬起” |
| 声学 | 接触/冲击时刻 | 44.1 kHz 起；需估计/标定声传播延迟 |
| 图像 | 笔画/痕端位置 | 与力/声同一触发；保留原始灰度 |

## 2. 时间尺度估算（基于 v2 S4–S6 当前占位参数）

| 目标 | 当前模型量级 | 采样/带宽起步估算 |
|---|---|---|
| 黏滑周期/慢运动 | 0.3–4 ms（S4/S6，$v=0.1$–0.5） | 声学/视频可按任务；240 fps 仅够慢相 |
| 停止点/划痕结束 | $t_{\rm stop}=0.33$–1.69 ms（$v=0.1$–0.5）；$v=0.05$ 时约 0.06 ms | 按 0.05–0.1 ms 事件设计 → ≥100 kS/s，力传感器带宽 ≥20 kHz |
| $N$ 振铃 | 周期约 0.6 ms（约 1.7 kHz） | ≥20 kS/s 可分辨；≥100 kS/s 更稳 |
| 冲击/撞击 | 亚毫秒 | 声学 44.1 kHz + 力通道 ≥100 kS/s |
| 痕端“台阶” | 与 stop point 同步，目前模型为连续过渡 | 需与图像/力同步判定，不能只靠采样率宣称 |

> 这些是量级估算，不是验收标准。最终采样率/带宽应由“目标事件内至少 10 个点 + 传感器实际频响 + 安装共振”共同确定；不能只看 ADC 标称采样率。

## 3. 三层测量链

1. **周期/接触事件层**：声学 + 慢视频，给周期、接触/脱离时刻；声学需标定传播延迟；
2. **$N(t)$ 卸载/停点波形层**：法向 + 切向力同步；检查零点、惯性、安装共振、滤波群延迟；
3. **痕端微观层**：停点附近 $v_{\rm rel}(t)$、$N(t)$、离面位移、声学脉冲；用于区分黏着/脱离/冲击。若设备不能覆盖最短时间尺度，明确标为“当前不可检验”，不给出肯定/否定结论。

## 4. 判定表（与 E6A 共用）

| 观察 | 判定 | 后续模型动作 |
|---|---|---|
| 痕端 $N$ 有限、$v_{\rm rel}\to0$、无撞击声 | 黏着截断 | v2 用 spring-slider/静摩擦；$N_c$、$I_c$ 记录 |
| 痕端 $N$ 快速降到 0、离面位移>阈值 | 动力脱离 | v2 加单边接触/冲击律；检查 $k_n$、恢复系数 |
| 痕端 $N$ 突变、明显撞击声/飞离 | sprag-slip/反向颤振 | LCP/冲击模型；检查 $\mu_s/\tan\theta$ 与柔度 |
| $N$、$v_{\rm rel}$ 均无变化，仅灰度变淡/消失 | 观测/沉积/磨损问题 | 先修 E6 观测模型，不改接触动力学 |

## 5. 同步与数据记录

- 共同触发：电机启动/电磁铁释放同时给 LED 与 DAQ 触发；记录各通道时钟偏差（目标 <1 个采样间隔）；
- 记录采样率、滤波（类型/截止/阶数）、传感器型号/量程/带宽、安装方式、零点漂移；
- 每条笔画记录：工况 ID、$v$、$N_0$、接触角、$k_x/k_y$ 配置、粉笔批次/磨损、温湿度；
- 原始数据 + 处理脚本 + 结果表一起归档（不要只留截图）。

## 6. 验收标准

- [ ] 力通道在已知动态载荷（敲击/落球）下验证带宽与相位延迟；
- [ ] 声学通道的传播延迟已标定；
- [ ] 至少一套工况能明确判出痕端事件类型（黏着/脱离/冲击之一），并给出不确定度；
- [ ] 若不能判定，明确记录“不可判定”及原因（带宽/同步/信噪比）；
- [ ] 数据格式满足 E6A 与 S4 对照需求（时间戳、通道、单位、采样率）。

## 7. 与 E6A 的分工

- **E5**：直接测力/运动/声学，给出“痕端发生了什么”；
- **E6A**：从图像灰度轮廓给出“痕端看起来怎样”，并检验表观截断；
- 两者必须在同一工况、同一时间基准下联合分析，才能把“强度截断”归因到具体机制。
