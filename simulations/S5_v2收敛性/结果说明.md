> 目标：检查 S4 基线 A 的“$N$ 平台 + 有限强度截断”结论是否对数值参数稳健。

| 接触阻尼 $c_n$ | 0.1、1、10 |

## 3. 判读

**① $\sigma_0$、rtol、$c_n$ 的收敛性良好。** $\sigma_0$ 从 $10^4$ 到 $10^6$ 变化时，$t_{\rm stop}$、$\xi$、$I_{\rm plateau}$ 变化均 <3%；rtol 从 $10^{-6}$ 到 $10^{-10}$ 的指标完全一致；$c_n=0.1$–10 只带来 <4% 变化。这说明“平台+截断”的定性结论不依赖这些数值参数。

**② 接触刚度 $k_n$ 的刚性极限没有收敛。** $k_n$ 从 $2\times10^3$ 增到 $2\times10^6$ 时，$N$ 相对涨落从 0.3% 增到 47.8%，$t_{\rm stop}$ 从 1.67 ms 变到 0.08 ms，$I_c/I_p$ 从 1.00 变到 0.14。这与 v1 中“输出对 $k_c$ 全程敏感”的问题类似，但机制不同：这里 $k_n$ 与接触阻尼/刚性比共同控制接触振铃；单纯增大 $k_n$ 会让罚接触更刚，DOP853 在接触事件附近的分辨率不足，且没有刚性接触极限。

**③ 对实验/建模的含义：**

- 不能把 S4 基线 A 的**绝对数值**（$t_{\rm stop}=1.689$ ms、$\xi=0.459$ mm、$I_p=1.918$ J/m）当作与参数无关的预言；它们依赖 $k_n$ 的取值；
- 但“平台 + 有限强度截断”的**定性形态**在 $k_n=2\times10^3$–$2\times10^4$ 区间、以及 $\sigma_0$/rtol/$c_n$ 全部测试点上都成立；
- $k_n$ 必须由 E4/E5 的整段 $N(t)$ 标定；若要得到真正的刚性接触极限，应改用 LCP/事件驱动接触（或至少高阻尼 + 更小 max_step 的收敛性研究），不能只把 $k_n$ 调大。

## 4. 验收状态

| 检查 | 状态 |
|---|---|
| $\sigma_0$ 收敛 | ✅ |
| 积分容差收敛（rtol $10^{-6}$–$10^{-10}$） | ✅ |
| 接触阻尼（0.1–10）稳健 | ✅ |
| $k_n$ 刚性极限收敛 | ❌（需要 LCP/事件驱动接触） |
| 强度守恒 | ✅（全部 1.000±0.0002） |

**结论：**S5 支持“平台+截断”的定性结论，但指出接触刚度是当前 v2 的主要数值/物理缺口；后续 S6/S7 与 E4/E5 都应带着这一限制解读。
