# 仿真 S3：LuGre 鬃毛本构替换 tanh · 结果说明

日期：2026-10-23
代码：`code/仿真S3_LuGre本构对比.py`
对应研究记录：《新参考文献与N下降段方向对照笔记》接缝一"可直接执行的动作 ②"
前置：仿真 S2（ε 灵敏度扫描）

> **适用边界补充（2026-10-25）：**本结果仅属于固定铰轴、轴向自由度冻结的 N 下降段退化子模型，不构成候选 A/B 手模型比较，也不包含完整周期。摩擦翻转、换向滞后和折叠峰均为数值预言，不是实验事实。旧符号 `k_c` 现统一记为接触刚度 **k_n**；参数证据见 `docs/研究记录/参数与证据总表.md`。
>
> **参数与测量限制：**μ_s=1.15μ_k、σ₀、σ₁、σ₂、v_s 均非本课题实测；E1/E2 的稳态摩擦数据不足以唯一辨识全部 LuGre 参数，未完成动态辨识前本模型只作定性机制与趋势模型。第 4 节“力传感器 ≥10 kHz 可检验换向滞后”应修正为按目标重新设计：0.115 ms 滞后约需 87 kS/s 起步，0.009 ms 约需 1.11 MS/s 起步并配微秒级同步；普通手机与 LED 对齐不能承担最短滞后判决。σ₀=1e5、σ₁=100 点的双容差差异约 49 ms，细节值继续禁止作定量引用。

## 1. 设置

| 项 | 值 |
|---|---|
| 对比基准 | tanh（ε=0.02，S2 名义值） |
| LuGre 内态 | ż = v_rel − σ₀\|v_rel\|z/g(v)，g(v) = N[μ_k + (μ_s−μ_k)e^(−(v/v_s)²)] |
| 参数网格 | σ₀ ∈ {1e5, 3e5} N/m × σ₁ ∈ {0, 30, 100} N·s/m，σ₂ = 5，v_s = 0.01 m/s |

| 工况 | k_c = 2e4 N/m，N₀ = 4 N，ω₀ = 0，v = 0.5 m/s（S1/S2 名义点） |
| 初值 | z₀ = g(v₀)/σ₀（继承前半个周期的滑动稳态） |

## 3. 结论与判读

**① 摩擦翻转在 LuGre 下天然涌现，但比 tanh 早 25%–33%。**
机制清楚：v_rel→0 时 tanh 的摩擦同步归零，而 LuGre 的鬃毛记忆 + Stribeck 静摩擦峰（μ_s N）使前向摩擦在翻转前维持 ~1.6 N——前向推力更大，尖端提前赶上板速。**翻转不是正则化伪影**（两种本构都给），但**翻转时刻的定量值是本构相关的**。

**② 换向滞后是本仿真最核心的新物理。**
摩擦力换向晚于速度换向 0.009–0.115 ms（tanh 恒为 0）。滞后随 σ₁ 增大单调缩小——σ₁ 是"从 LuGre 回归 tanh"的旋钮。这给出可检验的微观图像：翻转附近摩擦不是瞬时换向，而有 ~10⁻²–10⁻¹ ms 量级的记忆窗口（Heslot 蠕变图像在本模型中的对应物）。

**③ 最不确定的参数 σ₀ 影响 <3%——结论对鬃毛刚度稳健。**

**④ 跨本构稳健性分级（S3 的核心价值，给实验对照划线）：**

| 量 | tanh 族内（S2） | 跨本构（S3） | 实验可用性 |
|---|---|---|---|
| t* | 稳健 | 变化 −5%~−11% | 可用（±10%） |
| 翻转存在性/两阶段图像 | 稳健 | 稳健 | 可用 |
| t_flip 定量值 | 稳健（窗口内） | **偏移 −25%~−33%** | 仅定性 |
| I_2nd 绝对值 | 稳健（窗口内） | **+28%~+52%** | 需 μ_s 真值 |
| I(ξ) 折叠峰位置 | 峰位稳健 | **峰位前移（0.122→~0.085 mm）** | 仅定性 |
| I(ξ) 微结构 | — | 鬃毛尺度振荡（σ 占位参数所致） | 不可对照 |

**⑤ 数值经验（写进代码文档）**：z₀ 必须继承滑动稳态（σ₁ż 否则在 t=0 爆发 ~150 N）；分离点 g=0 需掩膜；σ₁ ≥ 300 N·s/m 超出稳定区。

## 4. 对研究路线的影响

1. **S2 的结论升级**："tanh 窗口内稳健"现在有了边界——定性图像（两阶段、折叠、翻转存在）跨本构稳健，定量时刻/强度/峰位必须等 **E1 给出 μ_s、E4 标定 k_c** 之后用 LuGre 定稿。
2. **换向滞后是新预言**：力传感器（≥10 kHz）测 N(t) 的同时，若能同步测摩擦力（切向力传感器或弹性臂应变），可检验 0.01–0.1 ms 的换向滞后窗口——这是 tanh 与 LuGre 的可区分实验特征。
3. **下一步**：仿真 S4 建议做 (μ, h/L) 参数平面扩展（S1 遗留的 Painlevé 触发边界）；或转实验侧（E1 先行）。
