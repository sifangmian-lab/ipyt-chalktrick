# 仿真 S4：v2 正交弹簧 + 弹性杆基线 · 结果说明

> 日期：2026-10-25  
> 代码：`code/仿真S4_v2正交弹簧基线.py`  
> 规格：`docs/研究记录/模型v2规格_2026-10-25.md`  
> 性质：**P0-3 最小实现 + 基线**。用于检验 v2 是否能产生“$N$ 平台 + 有限强度截断”，以及手端柔度对 $N$ 的控制作用；**不是**实验拟合，也不是完整周期模型。

## 1. 模型与设置

3 自由度集总模型 $q=(x_H,y_H,\theta)$：

- 手端两个正交弹簧 $k_x$（切向）、$k_y$（法向）连到固定支架；
- 杆为刚体 + 等效弯曲弹簧 $k_\theta$；
- 板面接触：法向罚弹簧 $k_n$（单边，$N\ge0$）；
- 切向为 LuGre 摩擦（含 $\mu_s$ 峰、Stribeck 速度 $v_s$）；
- 板以 $v$ 沿 $-x$ 运动；初始为“给定压入量 + 滑动稳态内态”的瞬态起点；
- 积分 DOP853，$t_{\max}=10$ ms，接触分离事件终止。

参数见 `S4_基线_结果表.csv`；三组基线：

| 工况 | $k_x$ | $k_y$ | $k_\theta$ | $v$ | 备注 |
|---|---:|---:|---:|---:|---|
| A | 300 | 1e6 | 1000 | 0.5 | 软切向 + 硬法向/转动（预期平台） |
| B | 1000 | 1e5 | 100 | 0.5 | 降低法向/转动刚度（预期 $N$ 明显变化） |
| C | 300 | 1e6 | 1000 | 0.05 | 实验窗口下限，检查低速行为 |

## 3. 判读

**① v2 可以实现 $N$ 平台。** 基线 A 在初始约 2 ms 的振铃后，$N$ 稳定在 3.71–4.00 N（相对涨落 1.0%），且 10 ms 内未失接触。这与 v1 中“$N$ 由 4 单调降到 0”形成明确对照：只要手端法向/转动足够硬、切向足够软，法向力就可以不被切向滑移“拖”到零。$k_y$ 因此是“平台 vs 几何卸载”的关键控制参数。

**② 手端柔度显著改变 $N$ 历史。** 基线 B 把 $k_y$ 从 $10^6$ 降到 $10^5$、$k_\theta$ 从 $10^3$ 降到 $10^2$ 后，$N$ 在 1.49–4.00 N 之间变化（相对涨落 15.3%），且 $\xi$ 跨度增大到 1.36 mm。这说明“痕端强度轮廓”对 $k_x/k_y/k_\theta$ 敏感，可作为 v2 与实验对照的判别量；也说明不完成 E3 的柔度标定，v2 不能给唯一预言。

**③ 目前尚未得到“干净的平台 + 有限强度截断”。** 基线 A 的 $I(\xi)$ 仍呈振荡/下降收尾（约 4.7→1.4 J/m），不是实验所见的“平台后阶跃截断”。原因至少有三类：

1. **初始瞬态**：当前从“已滑动 + 滑动稳态内态”开始，前 2 ms 有强振铃，污染强度轮廓；应从黏着态开始算完整周期；
2. **LuGre 的黏着过渡是光滑的**：$v_{\mathrm{rel}}\to0$ 时摩擦力连续趋于静摩擦值，$I=|F_f|$ 也随之连续变化，不一定给出阶跃；需要 spring-slider（弹性 Coulomb）或更硬的 $\sigma_0$ 对照；
3. **沉积律**：当前 $q=|F_f v_{\mathrm{rel}}|$ 在 $v_{\mathrm{rel}}\to0$ 时自然趋于 0；若实验截断由“黏着开始”而非“力突变”造成，则 $I(\xi)$ 在痕端出现有限值台阶还需要正确的静摩擦/黏着判据。

**④ 低速工况 C 过度“粘”。** $v=0.05$ m/s、当前占位 LuGre 参数下 stick 占比 70.8%、$\xi$ 仅 0.014 mm，说明低速端摩擦参数（$\mu_s-\mu_k$、$v_s$、$\sigma_0$）必须由 E1/E2 标定，不能直接沿用 v1 的占位值。

## 4. 验收状态（对照 P0-3）

| 验收项 | 状态 |
|---|---|
| v2 最小模型可运行、守恒 $\int I\,d\xi=I_{2\mathrm{nd}}$ | ✅（A/B/C 均在 1.000±0.0004） |
| 至少一个参数区给出 $N$ 平台 | ✅（基线 A，1.0% 涨落） |
| 平台 + **有限强度截断** | ❌ 尚未；当前为振荡/下降收尾 |
| 对 $k_n,\varepsilon$、模态/阻尼收敛 | ⏳ 未做（S5） |
| v1 极限回归 | ⏳ 未做 |
| 完整周期/周期解 | ⏳ 未做 |

**结论：** P0-3 的“模型实现 + 平台验证”已完成；**“截断”验收未通过**，下一轮应优先做“从黏着态开始的完整周期 + spring-slider 对照 + 低速参数标定”，而不是继续在当前瞬态上扫参数。

## 6. 下一步

1. 从黏着态开始积分完整周期（或长时积分取极限环），只分析“滑移段”的 $I(\xi)$；
2. 用 spring-slider（弹性 Coulomb）替换/对照 LuGre，检查痕端是否出现有限强度阶跃；
3. 扫描 $k_yL/(mg)$、$k_\theta/(k_yL^2)$、$\mu_s/\mu_k$、$v$，画出“平台/卸载/黏着/跳跃”相图（S6）；
4. 数值收敛（S5）与 v1 极限回归；
5. 接入 E3 的 $k_x,k_y,k_\theta$ 与 E1/E2 的 $\mu_s,\mu_k$ 实测值后，再讨论与实验强度轮廓的定量对照。
