# ipyt-chalktrick

粉笔虚线（Chalk Trick）现象——用粉笔在黑板上划线时出现虚线/断线现象的实验研究与理论建模项目。

## 项目简介

本项目研究粉笔划线"虚线戏法"现象：粉笔在黑板上运动时，划痕呈现周期性虚线而非连续实线。项目包含文献综述、实验方案与指导手册、理论模型（N 下降段完整模型、划痕相对强度时空依赖模拟）以及数值计算代码。

## 目录结构

```
├── docs/                    # 文档
│   ├── 文献综述/            # 文献调研与综述（Markdown + Word）
│   ├── 研究记录/            # 研究计划与阶段记录
│   ├── 实验指导/            # 实验方案、阶段实验详解、E1 指导手册（PDF/DOCX）
│   └── 模型报告/            # 建模与数值模拟报告（PDF）
├── code/                    # 代码
│   ├── 粉笔_N下降段_完整模型.py      # N 下降段完整理论模型与求解
│   ├── 划痕相对强度_时空依赖.py      # 划痕相对强度时空依赖模拟
│   └── tools/               # 辅助工具（LaTeX 公式渲染、字体转换、PDF 构建）
├── simulations/             # 初期仿真实验（S1 k_c 刚性极限收敛扫描等，含输出数据、结果图与结果说明）
├── figures/                 # 图表
│   ├── 结果图/              # 数值模拟结果图
│   ├── 公式/                # LaTeX 渲染的公式图片
│   └── 预览/                # 过程预览图
└── assets/
    └── fonts/               # 报告用字体（思源宋/黑体子集）
```

## 分支结构

- `trunk`：主分支（由原始 `main` 重命名而来），保存整理后的完整项目
- `develop`：开发分支，日常修改在此进行，稳定后合入 `trunk`

## 说明

- 代码中的路径为实验环境绝对路径，运行时请按本地环境调整。
- `code/tools/render_latex_eqs.py` 依赖外部 LaTeX；`build_pdf.py` 依赖 reportlab 与 `assets/fonts/` 中的字体。
