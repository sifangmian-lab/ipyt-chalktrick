# ipyt-chalktrick

粉笔虚线（Chalk Trick）现象——用粉笔在黑板上划线时出现虚线/断线现象的实验研究与理论建模项目。

## 项目简介

本项目研究粉笔划线"虚线戏法"现象：粉笔在黑板上运动时，划痕呈现周期性虚线而非连续实线。项目包含文献综述、实验方案与指导手册、理论模型（N 下降段完整模型、划痕相对强度时空依赖模拟）以及数值计算代码。

## 阅读顺序与当前有效版本

接手本项目的 agent 请先阅读 [Agent 交接说明](docs/研究记录/Agent交接说明.md)，再阅读 [研究进度评审](docs/研究记录/研究进度评审_2026-10-24.md) 和 [参数—证据总表](docs/研究记录/参数与证据总表.md)，了解研究进度、模型边界、参数来源、S1–S3 结果与后续任务。

- **实验方案当前有效版本：**[虚线戏法 ChalkTrick 实验与理论建模方案（Markdown）](docs/实验指导/虚线戏法ChalkTrick实验与理论建模方案.md)。同目录 DOCX 为排版版，若细则不一致，以 Markdown 和参数—证据总表为准。
- **模型边界：**主模型及 S1–S3 仅为固定铰轴、轴向自由度冻结、尖端罚弹簧接触的 **N 下降段退化子模型**，不包含上升段、自由飞行、再接触/碰撞、多周期，也不等同于候选 A/B 完整手模型。所有仿真结果均为数值预言，不是实验事实。
- **数据状态：**当前仓库未见可用于最终标定的 E1/E4 原始数据与标定表。N₀、ω₀为人工交接输入，接触刚度及若干本构参数仍待标定或为占位值；不得把数值结果写成“实验已经证实”。
- **符号约定：**接触刚度 **k_n**（旧 S1–S3 的 `k_c`）；结构/手模型刚度 `k`、`k_x`、`k_y`、`k_a`；率态临界刚度 **k_crit**。旧文件名和旧结果表保留历史符号，按上述映射阅读。
- **旧版手册提示：**`虚线戏法第一阶段实验详解与搭建指导.pdf` 与 `实验E1指导手册_静摩擦系数及其时间依赖.pdf` 仍是早期单向弹性臂/手刚度口径；涉及手模型时以当前方案 Markdown 的 E3 两候选规程为准。

## 运行与复现说明

- 两个早期主模型脚本及 PDF 工具含实验环境绝对路径，运行时请先改为本地或项目相对路径。
- S1–S3 依赖 NumPy、SciPy、Matplotlib，输出 CSV/PNG；先查看脚本参数入口，不要假定所有路径均已命令行化。
- `code/tools/render_latex_eqs.py` 依赖外部 LaTeX；`build_pdf.py` 依赖 ReportLab、Pillow 与 `assets/fonts/` 中的字体。
- 修改数值模型后，至少检查分离事件方向、接触掩膜、初始内态、积分容差、网格/分箱敏感性和输出单位；不要仅靠提高积分精度“修复”物理非光滑问题。
